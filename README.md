# 小说结构分析器

纯前端网页工具，**双击就能用**。分析成功小说的结构节奏，生成带节奏控制的大纲。

## 快速开始

1. **打开** — 双击 `index.html`（或部署到 GitHub Pages）
2. **拖入小说** — 把小说 .txt 拖到上传区
3. **提取指纹** — 点"分析"自动提取节奏/情绪/对话数据
4. **合成模板** — 拖多本书，合成通用节奏模板
5. **生成大纲** — 填题材/章数，直接输出带节奏标注的章节大纲
6. **复制给 AI** — 把大纲文本粘贴到 DeepSeek/Claude 细化情节

## 功能

### 文件管理
- 拖拽或点击上传 .txt / .json 文件
- 支持批量导入

### 单书分析（提取结构指纹）
- 自动分章
- 逐章统计：字数、段落、对话占比、情绪值、节奏分
- 角色出场频率
- 节奏/情绪曲线图

### 多书合成（通用模板）
- 2 本以上即可合成
- 百分比归一化对齐不同长度的书
- 输出平均值 + 标准差 + 置信度
- 喂越多越准

### 差异对比
- 你的小说 vs 通用模板
- 逐章标注节奏/情绪偏差

### 大纲节奏生成器
- 选题材（言情/悬疑/热血/都市…）
- 选情绪基调（甜宠/虐心/轻松/沉重…）
- 自动分配每章：节奏目标、情绪目标、对话占比、冲突类型、字数建议
- 甜虐交替自动控制（连续甜≤5章，连续虐≤4章）
- 支持使用已合成模板调整节奏分配

## 数据持久化

- 分析结果可导出为 `.json` 指纹文件
- 下次用直接把 `.json` 拖回网页
- 推荐在硬盘建立 `指纹库/` 文件夹长期保存

## 部署到 GitHub Pages

1. 在 GitHub 创建仓库（如 `novel-analyzer`）
2. 把 `index.html` + `emotion_dict.js` + `name_dict.js` 推上去
3. 仓库 Settings → Pages → 选 main 分支
4. 等 2 分钟，获得外链

## 隐私

所有文件**不上传任何服务器**。数据在浏览器内存中处理，关页面即消失。

## 技术

纯前端，零依赖。一个 HTML + 两个 JS 数据文件。
